# giant-solutions.eu

Website for Giant Solutions: AI engineering consulting and the book *AI for Developers*, by George Gens.

Built with [Astro](https://astro.build) and Tailwind CSS, deployed on Netlify.

```sh
npm install
npm run dev     # http://localhost:4321
npm run build   # build + check that the frozen legacy URLs are unchanged
```

See [AGENTS.md](AGENTS.md) for project rules, especially the frozen files in `public/`.

Older pages in `public/` were based on the MIT-licensed [App Landing Page](https://github.com/tailwindtoolbox/App-Landing-Page) template by Tailwind Toolbox; see [LICENSE](LICENSE).
